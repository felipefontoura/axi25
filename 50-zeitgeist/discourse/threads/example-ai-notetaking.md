# [EXEMPLO] Andrej Karpathy on Twitter: "Your LLM should be writing your wiki"

URL: https://twitter.com/karpathy/status/example-thread-2026

---

**@karpathy** · Jan 12, 2026

your LLM should be writing your wiki, not just answering your questions

the mental model shift: stop using AI as a search engine you talk to. start using it as a librarian who lives in your notes and maintains them for you

🧵

---

**@karpathy** · Jan 12, 2026

the pattern is simple:

1. you capture (voice memo, quick note, paste)
2. the agent writes the atomic note
3. the agent links it to everything related
4. the agent flags contradictions

you review, you decide. the agent does the plumbing.

---

**@karpathy** · Jan 12, 2026

I've been doing this for ~6 months. the graph is now dense enough that the agent surfaces connections I didn't consciously make. that's the signal that the system is working

before: I'd read something, highlight it, forget it. now: the agent writes it into the permanent layer and links it forward

---

**@karpathy** · Jan 12, 2026

the hard part isn't the tech. it's building a schema the agent can navigate consistently

if your notes are unstructured blobs the agent can't help you. if your notes are structured atomic claims the agent can think with you

structure is the leverage point
