# [EXEMPLO] Atomic Notes

## Idea

An atomic note captures exactly one idea, stated completely enough to stand alone without its source context.

## Detail

The "atomic" constraint is the hardest part of building a knowledge base. The natural impulse is to dump everything from a chapter into a single file and call it done. But a file that contains twelve ideas is not a knowledge unit — it is a filing cabinet drawer. You cannot link a drawer; you can only link an idea.

A well-formed atomic note has a title that reads like a claim, not a topic. "Spaced repetition beats massed practice for retention" is atomic. "Spaced repetition notes" is not. The title should work as a reusable sentence you can drop into other notes — that is how links become arguments rather than mere citations.

The payoff accumulates slowly. After dozens of notes, you start discovering connections you never consciously made: a note on cognitive load from a UX book links naturally to a note on working memory from a neuroscience paper. The graph is showing you structure that was invisible in your source material. That emergence is what the Zettelkasten literature means when it says "the slip-box thinks for you."

Keeping notes atomic also forces you to understand before you write. You cannot write one clear sentence about an idea you only half-grasped. The act of writing the atomic note is a comprehension check.
