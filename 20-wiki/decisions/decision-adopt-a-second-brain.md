# [EXEMPLO] Decision: Adopt a Second Brain

## Context

By late 2025 the problem was obvious: I was reading a lot and retaining little. Books left impressions but no durable structure. Notes lived in three apps and two paper notebooks with no cross-referencing. When a question came up — "what did that book say about habit formation?" — the answer required a full search through disconnected silos, and half the time I gave up.

The trigger was discovering Karpathy's public writing on the wiki-llm pattern: using an LLM not just to chat, but to *maintain* a personal knowledge base. That reframed the whole problem. The question was not "which notes app?" but "how do I give an agent the right structure to think with me?"

## Options

1. **Status quo (scattered notes)** — low friction to start, but knowledge compounds nowhere. Every reading session starts from zero. Scales negatively.
2. **Roam / Logseq / Obsidian alone (no agent layer)** — better than scattered, but the linking work is entirely manual and the agent cannot participate meaningfully without a defined schema.
3. **AXI25 (structured vault + agent layer)** — higher upfront cost; requires learning the schema, building the habit, trusting the agent. If it works, knowledge compounds across years. Scales positively.

## Chosen

Option 3 — AXI25. The decision came down to one question: which option gets compoundingly better with time? Options 1 and 2 don't. A structured vault that an agent can read, write, and link does.

The risk is overhead: if the schema feels like bureaucracy, I'll stop using it. Mitigation is keeping captures frictionless (quick-capture inbox) and letting the agent handle the structural work.
